# Hotel Booking Demand - HMS Project

## What is this project?
Data science project analyzing hotel booking demand 
for two hotels in Portugal.

## Data Source
N. António, A. de Almeida, L. Nunes (2019), 
"Hotel booking demand datasets", Data in Brief 22, 41-49.

## How to run
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. Run notebooks in order 01 to 07
